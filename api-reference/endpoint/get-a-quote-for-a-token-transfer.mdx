Request an exact-input quote for a same-chain swap or cross-chain transfer. The response includes estimated output amounts, executable `calldata`, fees, and optional non-blocking `warnings`.

## Amounts

- `amount` is what the user pays, in base units, before Delora and integrator fees.
- `inputAmount` is what the route receives after those fees are deducted from `amount`.
- `outputAmount` is the estimate to show the user. `isSimulatedAmount` is `true` when it was measured by simulating the returned transaction.
- `minOutputAmount` is the minimum the transaction accepts. Show `outputAmount` as the expected amount, not this floor.

## Execute the quote

- **EVM origin:** send `calldata.to`, `calldata.data`, and `calldata.value` from `senderAddress`. For an ERC-20 input, first approve `approvalAddress` to spend at least the full `amount`, not only `inputAmount`. See the [EVM transaction flow](/examples/transaction-flow/ethereum).
- **Solana origin:** `calldata.data` is a base64-encoded serialized transaction, and `transactionSize` gives its size. See the [Solana transaction flow](/examples/transaction-flow/solana).

`executionRoute` describes the route the returned transaction executes. Its token fields can differ from the request; for example, an adapter can represent a native token as `0xeeee…eeee`. When the route swaps the input before bridging it, `sourceSwapProvider` names that exchange. When it converts the bridged token on arrival, `destinationSwapProvider` identifies that conversion.

## Slippage

- Without `slippage` or `slippageMode`, the route uses 0.5% (`0.005`).
- A numeric `slippage` is a budget for the whole route. When the route has several variable legs, such as a source swap followed by a bridge, the budget is split between them.
- `slippageMode=auto` lets Delora choose the tolerance: 10 bps for recognised stablecoin pairs and 50 bps for every other pair. It takes precedence over a numeric `slippage` value.

## Choose providers

`includeBridges`, `includeExchanges`, `excludeBridges`, and `excludeExchanges` take adapter keys from [`/v1/tools`](/api-reference/endpoint/get-tools). Excluded exchanges are also not used for the source swap of a Relay or Eco route or for a Relay destination conversion.

## When no route is found

When no adapter can serve the request, the API returns `422` with code `NO_AVAILABLE_QUOTES`. `details.failures` lists why each adapter or route dropped out. See [API errors](/api-reference/errors#quote-errors).
