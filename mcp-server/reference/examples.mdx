These examples show how to use the Delora MCP tools: typical prompts, tool arguments, and response structures. They are based on the [Delora API](https://api.delora.build) and the MCP server implementation. Quote responses use `adapter` plus a single `calldata` object, and may also include optional `warnings`.

## Example Prompts & Tool Calls

### Get Chain Information

**Prompt:** "What chains does Delora support?"

**Tool called:** `get_chains` (no arguments), or `get_chains` with `chainTypes: "EVM"` to filter.

**Response (key structure):**

```json
{
  "chains": [
    {
      "key": "eth",
      "name": "Ethereum",
      "chainType": "EVM",
      "id": 1,
      "idHex": "0x1",
      "mainnet": true,
      "rpcUrls": ["https://ethereum-rpc.publicnode.com", "https://eth.drpc.org"],
      "blockExplorerUrls": "https://etherscan.io/",
      "nativeToken": {
        "address": "0x0000000000000000000000000000000000000000",
        "decimals": 18,
        "symbol": "ETH",
        "chainId": 1,
        "coinKey": "ETH",
        "name": "ETH"
      }
    }
  ]
}
```

### List Tokens by Chain

**Prompt:** "What tokens are supported on chain 1?"

**Tool called:** `get_tokens` with `chains: "1"` or `chainTypes: "EVM"`

**Response (key structure):** Object keyed by chain ID, each value an array of token objects (address, symbol, decimals, chainId, name, coinKey, verificationStatus, logoURI, and price fields such as priceUSD and priceStatus when a price is available).

### Get a Cross-Chain Quote

**Prompt:** "Get a quote to transfer 1 USDC from Ethereum to Arbitrum"

**Tool called:** `get_quote` with:

```json
{
  "originChainId": 1,
  "destinationChainId": 42161,
  "amount": "1000000",
  "originCurrency": "0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48",
  "destinationCurrency": "0xaf88d065e77c8cC2239327c5EDb3a432268e5831",
  "senderAddress": "0x6352a56caadc4f1e25cd6c75970fa768a3304e64",
  "receiverAddress": "0x6352a56caadc4f1e25cd6c75970fa768a3304e64",
  "slippage": 0.005
}
```

**Response (real response, trimmed):**

```json
{
  "inputAmount": "998500",
  "outputAmount": "974693",
  "isSimulatedAmount": false,
  "executionRoute": {
    "originChainId": 1,
    "destinationChainId": 42161,
    "originCurrency": "0xa0b86991c6218b36c1d19d4a2e9eb0ce3606eb48",
    "destinationCurrency": "0xaf88d065e77c8cc2239327c5edb3a432268e5831",
    "senderAddress": "0x6352a56caadc4f1e25cd6c75970fa768a3304e64",
    "receiverAddress": "0x6352a56caadc4f1e25cd6c75970fa768a3304e64"
  },
  "minOutputAmount": "969820",
  "estimatedTimeSec": 1,
  "adapter": "RELAY",
  "calldata": {
    "to": "0x8FE04AcCD609b7Aa08a03Ef7cfa2B04E2A1A5d3d",
    "value": "0x00",
    "data": "0xa3443faa..."
  },
  "fees": {
    "total": { "amount": "47614", "currencySymbol": "USDC", "currencyAddress": "0xa0b86991c6218b36c1d19d4a2e9eb0ce3606eb48", "chainId": 1, "decimals": 6 },
    "breakdown": [
      { "type": "gas", "amount": "26648326785536", "currencySymbol": "ETH", "chainId": 1, "decimals": 18, "amountUsd": "0.059400" },
      { "type": "relayer", "amount": "23807", "currencySymbol": "USDC", "chainId": 1, "decimals": 6, "amountUsd": "0.023802" },
      { "type": "relayerGas", "amount": "3704", "currencySymbol": "USDC", "chainId": 1, "decimals": 6, "amountUsd": "0.003703" },
      { "type": "relayerService", "amount": "20103", "currencySymbol": "USDC", "chainId": 1, "decimals": 6, "amountUsd": "0.020099" }
    ],
    "totalUsd": "0.107004"
  },
  "warnings": [],
  "gas": {
    "maxFeePerGas": "0x7e5f2622",
    "maxPriorityFeePerGas": "0x6b49d200"
  },
  "approvalAddress": "0x8FE04AcCD609b7Aa08a03Ef7cfa2B04E2A1A5d3d"
}
```

Key points:

* **`inputAmount`**: The requested `amount` after Delora and integrator fees are deducted.
* **`outputAmount`**: Estimated amount on the destination chain (in smallest units). `isSimulatedAmount` says whether it was measured by simulating the transaction.
* **`minOutputAmount`**: The minimum the transaction accepts. Show `outputAmount` as the expected amount.
* **`calldata`**: Transaction payload to sign and submit with your wallet. For an ERC-20 input, first approve `approvalAddress` to spend the full `amount`.
* **`fees`**: Total and breakdown (gas, relayer, etc.) in USD and token amounts.
* **`warnings`**: Optional non-blocking issues that do not prevent Delora from returning a quote.

### Same-Chain Swap Quote (1 ETH to WETH on Arbitrum)

**Prompt:** "Quote swapping 1 ETH to WETH on Arbitrum"

**Tool called:** `get_quote` with:

```json
{
  "originChainId": 42161,
  "destinationChainId": 42161,
  "amount": "1000000000000000000",
  "originCurrency": "0x0000000000000000000000000000000000000000",
  "destinationCurrency": "0x82af49447d8a07e3bd95bd0d56f35241523fbab1",
  "senderAddress": "0x6352a56caadc4f1e25cd6c75970fa768a3304e64",
  "receiverAddress": "0x6352a56caadc4f1e25cd6c75970fa768a3304e64",
  "slippage": 0.005
}
```

**Response (real response, trimmed):**

```json
{
  "inputAmount": "998500000000000000",
  "outputAmount": "998500000000000000",
  "isSimulatedAmount": true,
  "executionRoute": {
    "originChainId": 42161,
    "destinationChainId": 42161,
    "originCurrency": "0xeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeee",
    "destinationCurrency": "0x82af49447d8a07e3bd95bd0d56f35241523fbab1",
    "senderAddress": "0x6352a56caadc4f1e25cd6c75970fa768a3304e64",
    "receiverAddress": "0x6352a56caadc4f1e25cd6c75970fa768a3304e64"
  },
  "minOutputAmount": "993507500000000000",
  "adapter": "OKX",
  "calldata": {
    "to": "0x12B797D9d7947c4cb97e87178182835e31530597",
    "data": "0x736eac0b...",
    "value": "0x0de0b6b3a7640000"
  },
  "warnings": [],
  "gas": {
    "gasPrice": "0x016eb940"
  }
}
```

Use `0x0000000000000000000000000000000000000000` for native currency (ETH). Amount is in wei (18 decimals); `0x82af49447d8a07e3bd95bd0d56f35241523fbab1` is WETH on Arbitrum. `executionRoute` shows the route the selected adapter executes, so its token fields can differ from the request: here the adapter represents native ETH as `0xeeee…eeee`.

## Code Samples

Connect to the Delora MCP server programmatically.

### TypeScript MCP Client (streamable HTTP)

```typescript
import { Client } from "@modelcontextprotocol/sdk/client/index.js";
import { StreamableHTTPClientTransport } from "@modelcontextprotocol/sdk/client/streamableHttp.js";

const transport = new StreamableHTTPClientTransport(
  new URL("https://mcp.delora.build/mcp")
);

const client = new Client({
  name: "delora-client",
  version: "1.0.0",
});
await client.connect(transport);

// List tools
const { tools } = await client.listTools();
console.log("Available tools:", tools.map((t) => t.name));

// Get chains
const chainsResult = await client.callTool({
  name: "get_chains",
  arguments: { chainTypes: "EVM" },
});
console.log("Chains:", chainsResult.content);

// Get quote (1 USDC Ethereum → Arbitrum)
const quoteResult = await client.callTool({
  name: "get_quote",
  arguments: {
    originChainId: 1,
    destinationChainId: 42161,
    amount: "1000000",
    originCurrency: "0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48",
    destinationCurrency: "0xaf88d065e77c8cC2239327c5EDb3a432268e5831",
    senderAddress: "0x6352a56caadc4f1e25cd6c75970fa768a3304e64",
    receiverAddress: "0x6352a56caadc4f1e25cd6c75970fa768a3304e64",
    slippage: 0.005,
  },
});
console.log("Quote:", quoteResult.content);

await client.close();
```

### Call get_instructions First

**Prompt:** "How do I use the Delora MCP server?"

**Tool called:** `get_instructions` (no arguments)

Returns the server’s built-in guide (workflow: get_chains → get_tokens/get_token → get_quote). Use this at the start of a session so the AI follows the recommended flow.
